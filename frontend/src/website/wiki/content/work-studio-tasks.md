# Work Studio · Tasks

The Task surface tracks the small unit of work that turns a decision
into a delivered outcome. Use it when a thread or compile has
produced something to do.

## What it does

A task carries a chip, a status, a readiness score, an owner, and an
objective. The readiness number tells you how close it is to landing,
not how complete it feels. Status pills show what kind of attention
the task needs next — input, decision, hand-off, sign-off.

## How to use it

1. Open Task Manager from the top nav.
2. Add a task with a one-line objective in italics. Specific verbs
   beat aspirational nouns.
3. Set an owner. Tasks without an owner do not move.
4. Watch the readiness bar. When it hits the threshold, the task is
   ready for the decision it has been pointed at.

**Worked example.** Following a Solva session, a CFO had three
candidate actions on the cross-sell math. The first became a task:
*"Pull Q3 channel-mix exposure for the West region; needs Rachel."*
Owner: Rachel. Readiness moved from 30 to 70 over four working days
as data landed. At 70 the bar tipped past the decision threshold and
the task surfaced in the CFO's Daily Review for sign-off.

## Common questions

- **Why isn't readiness a percentage of work done?** Because work
  done is not the same as decision-ready. Readiness measures the
  second.
- **Can I share tasks?** Within the workspace, yes. Outside the
  workspace, no — tasks carry context that does not travel.
- **What happens when a task is signed off?** It writes a row to the
  cycle audit trail and the readiness bar fills to 100.

## Troubleshooting

- **A task is stuck at the same readiness for a week.** That is the
  signal, not a bug. Open the task and find the actual blocker —
  usually a missing input or an unnamed decision.
- **The owner avatar isn't rendering.** Refresh the page. If it
  persists, the owner's account may have lost membership of this
  workspace.
