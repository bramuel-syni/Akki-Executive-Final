# Account · Multi-factor authentication

MFA adds a second factor — a 6-digit code from an authenticator app
— to the sign-in flow. Recommended for everyone, mandatory for
workspace admins.

## What it does

After MFA is enabled, sign-in asks for your email, password, and a
fresh 6-digit code generated by an authenticator app on your
phone. Without all three you cannot sign in. Stolen passwords alone
are not enough.

## How to use it

1. Open Account → Security.
2. Click "Enable MFA". Scan the QR code with any TOTP-compatible
   authenticator (1Password, Authy, Google Authenticator).
3. Type the 6-digit code the app displays.
4. MFA is now active. Every subsequent sign-in asks for a code.

**Worked example.** A chief executive sets MFA up on 1Password. Two
weeks later their laptop was lost on a train. The finder tried to
sign in and got past the email and password — both stored in the
browser. The MFA code blocked the attempt. The executive
unprovisioned the device from MFA, reset the password, and
continued the day.

## Common questions

- **Can I use SMS instead?** Not yet. TOTP only.
- **What if I lose my phone?** Sign in from a device that is still
  trusted and disable MFA from Account → Security, then re-enable
  with the new device. If no device is still trusted, contact the
  workspace admin to trigger a reset.
- **Can I print backup codes?** Backup codes are on the roadmap;
  they are not shipped yet.

## Troubleshooting

- **The code keeps being rejected.** Check the time on your phone
  is synced to network time. TOTP is time-sensitive — a clock that
  drifts by more than 30 seconds will break.
- **The QR code won't scan.** Use the secret string below the QR
  instead — paste it directly into the authenticator app.
