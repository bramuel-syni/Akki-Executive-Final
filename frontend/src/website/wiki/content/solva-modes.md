# Solva · Modes

Solva runs in four modes. Each mode shapes how Akki frames the work
and what it commits to deliver. Pick the mode that matches the kind
of question you are asking.

## What it does

The mode you pick changes the framing of the session, the kind of
output you receive, and the way citations are organised. The
underlying reasoning is structured and auditable in every mode.

## How to use it

1. Open Solva. The mode picker is the first step.
2. Choose:
   - **Seek clarity** — for an ambiguous situation you need to read
     before acting.
   - **Develop strategy** — for a forward-looking question with
     trade-offs to weigh.
   - **Simulate hypothesis** — for a "what would happen if" question.
   - **Get perspectives** — for a question where the disagreement
     matters more than the answer.
3. Frame the question. Solva audits the framing before reasoning.
4. Review the structured diagnosis when it arrives.

**Worked example.** A board chair facing a contentious capital
allocation decision opened Solva and picked *Get perspectives*.
Solva returned a diagnosis with three named positions, the strongest
counter to each, the assumptions each rests on, and the evidence
weighed for and against. The chair took it into the next meeting as
the structuring document for the conversation.

## Common questions

- **Can I switch modes mid-session?** No. Modes change the framing
  contract; start a new session.
- **Which mode is the default?** None. Solva asks you to pick
  because the pick matters.
- **Why no "answer me" mode?** Because Akki refuses to invent.
  Every mode commits to a position the evidence supports.

## Troubleshooting

- **I picked the wrong mode.** Discard the session and start again.
  Sessions are cheap.
- **A mode's output feels generic.** That means your framing was
  generic. Restate the question more specifically and re-run.
