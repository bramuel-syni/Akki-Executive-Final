# Work Studio · Chat

Work Studio Chat is a dedicated thread for one topic. Use it when you
want a working session that ends with a position, not a transcript.

## What it does

Chat keeps the context of a single question on one surface. Every
turn is cited where it draws on Akki's evidence base. Threads are
private to your account.

## How to use it

1. Open Work Studio from the top nav. Pick "Chat" from the surface
   selector.
2. Start a thread with the question you actually want to answer.
   Specific is better than abstract.
3. Reply to Akki's turns the way you would a trusted peer — give
   counter-evidence, name what's wrong, ask for what's missing.
4. When the thread is at a stopping point, hit "Compile" to fold the
   thread into a structured Solva diagnosis.

**Worked example.** A CFO opens Chat and writes "We're 11 months into
the post-acquisition integration and the cross-sell math has stopped
landing. What changed?" Akki returns a first-pass read with two
candidate causes. The CFO replies with a specific channel-mix
breakdown that contradicts one. Akki retracts that candidate, names a
third, and cites the source it pulled. After three turns the CFO hits
Compile and gets a one-page diagnosis with the audit trail intact.

## Common questions

- **Does Akki remember between threads?** No. Each thread is its own
  context. Compile is how you carry a thread forward.
- **Can I share a thread?** Not yet. Export to PDF for now.
- **What model does Akki use?** Akki routes across multiple LLM
  providers based on the task. Specifics live with the engine, not
  the chat surface.

## Troubleshooting

- **Akki says "I don't have evidence for that."** That's a working
  answer, not a failure. Add the evidence to the thread (paste, link,
  attach) and ask again.
- **A turn errors out.** Refresh and re-send. If it persists, check
  `/status` for an active incident.
