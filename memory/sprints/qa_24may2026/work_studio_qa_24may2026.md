- Status Badge - A status badge is added to every card to communicate the pack's lifecycle state at a glance. Three states are defined:

- Confidence Score

- Above 75% — neutral colour
- 50% to 75% — amber
- Below 50% — red

A fixed footer sits at the bottom of the page and remains visible at all times regardless of scroll position. The footer contains two areas:
- Agent Recommendation — the agent surfaces an enhancement recommendation based on its analysis of the compiled pack. This is displayed as a plain-language suggestion above the CTAs — for example "The executive summary could be strengthened with Q3 variance data from the Management Accounts."
Three CTAs: Refine, Decline, and Commit
Refine — the user accepts the agent's recommendation. The agent implements the suggested changes automatically. If an additional source document is required to complete the refinement, the file upload modal opens prompting the user to upload the relevant file. Once uploaded the agent proceeds with the refinement and the document content and Document Intelligence card update to reflect the changes.
Decline — dismisses the agent recommendation. The recommendation text is removed from the footer.
Commit — version-locks the pack. A confirmation modal appears informing the user that the pack will be locked and cannot be refined further once committed. Two options are presented: Confirm and Cancel. On confirm the page closes, the user is returned to the tab, and the committed card appears at the top of the list with a pulse animation and a lock icon overlay on the document icon. The card badge updates to Committed.

- The document intelligence in the side drawer mention in item 6  and shown in figure 8 to be update to cover the following:
- Confidence score — measures how well the enhanced output matches the user's instructions. A high score indicates the instructions were clearly interpreted and fully applied. A lower score signals that some instructions were ambiguous, partially applied, or could not be actioned.
- What was changed — a plain-language summary of the improvements made, mapped to the instructions the user provided.
- What was preserved — confirmation that citations, data references, and key figures from the original document were kept intact.
- Instructions applied — a record of the exact instructions the user submitted, providing a clear audit trail of what was asked and what was actioned.
- What was not changed and why — if any part of the instructions could not be applied, this is flagged with a plain-language explanation.

- The side drawer has three CTAs at the bottom: Save, Refine, and Delete.
- The Save button remains inactive until the user edits the title — it activates as soon as a change is made.
- The Refine button allows the user to add further instructions and re-enhance the document without starting from scratch. Clicking Refine opens a compact instruction input field within the side drawer. The user types additional instructions and submits. A loading state appears, the document is re-enhanced, and the Document Intelligence details update automatically to reflect the new version. The confidence score and all intelligence details update to reflect the latest enhancement pass. The title remains editable throughout. This turns the enhancement into an iterative refinement loop, allowing the user to progressively sharpen the document across multiple passes.
- Clicking Delete triggers a confirmation modal with two options: Cancel and Delete. Any changes made in the side drawer — including title edits and deletions — are reflected immediately on the corresponding entry in the Document Journal.
