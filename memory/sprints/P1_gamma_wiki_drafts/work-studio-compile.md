# Work Studio · Compile

Compile folds a Work Studio thread into a structured diagnosis. Use
it when you want a stopping-point artefact you can take into a
meeting.

## What it does

Compile reads the entire thread, weighs the evidence it surfaced,
runs the structured reasoning pipeline, and outputs a diagnosis. The
diagnosis carries the source citations from the thread plus the
deeper evidence Akki pulled mid-pipeline. The audit trail is
preserved.

## How to use it

1. From a Work Studio Chat thread, click "Compile" in the top right.
2. Pick the mode — `Seek clarity` for "what's actually going on",
   `Develop strategy` for "what to do about it", `Simulate hypothesis`
   for "what if we did X", `Get perspectives` for "what would a NED /
   sceptic say".
3. Wait. A compile usually takes 60-180 seconds depending on the
   thread length and the depth of evidence.
4. The diagnosis lands on the same surface, replacing the chat view.
   You can switch back to chat at any time.

**Worked example.** A founder has been arguing with Akki about whether
the November regulatory window is the right forcing function. After 8
turns the thread has the evidence in it but no clear position. The
founder hits Compile in `Get perspectives` mode. The diagnosis comes
back with three positioned reads (chair-facing, sceptic-facing,
executive-facing) and names where they disagree — which is exactly
what the founder needed to take into the board pre-read meeting.

## Common questions

- **Can I re-compile?** Yes. Each compile creates a new artefact;
  prior ones stay in the session history.
- **What gets cited?** Every numerical claim, every named source,
  every comparable. The audit page shows them all.
- **Why does Akki sometimes lower its confidence?** Because it
  couldn't honestly triangulate. That's by design — Akki refuses to
  invent.

## Troubleshooting

- **Compile fails mid-pipeline.** Open the session timeline; look for
  the last successful layer. Resume from there.
- **The diagnosis feels thin.** Add more evidence to the thread and
  re-compile. The artefact reflects what was weighed; thin input gets
  a thin read.
