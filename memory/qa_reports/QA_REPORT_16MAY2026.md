### QA-2026-05-16-030 · Overlay — Layer 1 Toolbar
- **Surface**: Document Overlay — Toolbar
- **Expected** (verbatim): *"The toolbar contains all primary actions and document-level controls. It is split into a left group and a right group. Left group: A back arrow to close the overlay and return to the document list; The document title, which is an inline editable field in Draft and In Review states. The user clicks the title, types the new name, and confirms with Enter or by clicking away. A dashed underline on hover signals editability. In Committed state the title is a plain static label with no editable affordance; The status badge showing the current lifecycle state — Draft, In Review, or Committed. Right group — Draft and In Review state: Undo; Redo; Version History — opens the Version History modal; Download — downloads the document in its source format with a PDF option available via dropdown; Save — saves the current state of the document as a version snapshot; Commit — the most visually prominent action, styled as a filled dark pill. Creates a new Draft copy of the committed document that the user can edit, following the full workflow from the beginning. The committed version is preserved as an immutable record. The Commit button is intentionally more prominent than all other toolbar actions. It is the most consequential action in the overlay and should be findable without searching."*

How it should work: When an objective or project is created, the default status is set to Not Started. … The objective profile drawer and the project profile drawer each include an Update button. A direct link to the Document Journal upload is provided. The same message applies for projects. The Update button can be clicked at any time — for example, after new documents are uploaded — to refresh the status based on the latest available data. The status assigned by Akki is not manually overridable. This preserves the data-driven integrity of the Monitor module and is consistent with the goal update mechanic in MN-02. This applies to both Exec and NED accounts."*
